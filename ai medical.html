AI Medical Chatbot System

Smart health guidance powered by AI & NLP

Roles Requirements Working Chatbot

Roles

User

Enters symptoms and receives advice.

System (Chatbot)

Analyzes input and generates appropriate responses.

Requirements

Hardware

  • Computer or mobile device
  • Internet connection

Software

  • Frontend: HTML, CSS, JavaScript
  • Backend: Python (Flask)
  • Database (optional): JSON / Text file

Working of the System

  1. User enters symptoms in the chatbot.
  2. Chatbot checks symptoms against a predefined dataset.
  3. Matching response is generated.
  4. User receives medical advice and precautions.
